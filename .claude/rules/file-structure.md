# File Structure

```
wimg/
├── CHANGELOG.md               auto-generated by release.sh
├── Makefile                   thin wrappers: dev, ios, android, test, check, deploy, release-*
├── lefthook.yml               pre-commit (zig fmt, gitleaks) + commit-msg check
├── i18n/en.ts                 translation source of truth
├── scripts/
│   ├── release.sh             version bump + changelog + commit + tag
│   ├── build-wasm.sh          compact WASM → wimg-sync/libwimg-compact.wasm
│   ├── build-ios.sh           XCFramework
│   ├── build-android.sh       libwimg.so (arm64-v8a)
│   ├── gen-xcodeproj.sh       regenerate .xcodeproj from project.yml
│   ├── build-all.sh           all of the above
│   ├── dev.sh                 local sync server on :8787 (Worker, or native with WIMG_NATIVE_SYNC=1)
│   ├── deploy-server.sh       landing page + sync server → VPS (from a Mac)
│   ├── i18n-codegen.ts        en.ts → Translations.swift + Translations.kt
│   ├── test-bank-matrix.ts    FinTS top-bank anonymous init probe
│   ├── check-bank-drift.ts    official bank CSV vs banks.zig
│   ├── fints-dump.ts / test-fints-mock.ts   FinTS debugging aids
├── .github/workflows/
│   └── release.yml            CI (see release.md)
├── infra/                     Caddy fragments, systemd units, restic, VPS scripts
├── wimg-site/                 static landing page (build.py → public/)
│
├── libwimg/
│   ├── build.zig              wasm (compact default) / native / -Dshared=true for Android
│   ├── include/libwimg.h      C header
│   ├── vendor/                sqlite3.c (gitignored), wasm_vfs.c, libc_shim.c
│   └── src/
│       ├── root.zig           C ABI exports (+ FinTS native-only)
│       ├── db.zig             SQLite wrapper + schema + migrations
│       ├── parser.zig         CSV parsers (Comdirect, TR, Scalable)
│       ├── categories.zig     keyword rules
│       ├── booking.zig        booking-type prefixes → row title + kind
│       ├── recurring.zig      recurring detection
│       ├── summary.zig        monthly summaries
│       ├── crypto.zig         HKDF + XChaCha20-Poly1305
│       ├── types.zig, sqlite_c.zig, dbg.zig
│       ├── fints.zig          FinTS 3.0 protocol engine (native only)
│       ├── fints_http.zig     HTTP via platform callback (native only)
│       ├── mt940.zig, camt.zig   statement parsers
│       └── banks.zig          German bank list (BLZ + FinTS URLs)
│
├── wimg-ios/
│   ├── project.yml            XcodeGen spec (wimg.xcodeproj is generated)
│   ├── plugins/WimgI18n/      #L macro + generated Translations.swift
│   ├── wimgWidget/            WidgetKit extension
│   └── wimg/
│       ├── wimgApp.swift      entry + TabView (Suche, Home, Umsätze, Mehr)
│       ├── LibWimg.swift      Swift wrapper over the C ABI
│       ├── Models/ Services/ Components/
│       └── Views/             Home, Transactions, Analysis, Recurring, Review,
│                              Import, FinTS, Search, Settings, About, More, Onboarding, Lock
│
├── wimg-android/app/src/main/
│   ├── cpp/wimg_jni.c         JNI shim
│   └── java/com/wimg/app/
│       ├── bridge/            LibWimg.kt, WimgJni.kt
│       ├── i18n/Translations.kt   generated, + L()
│       ├── services/          Sync, BackgroundRefresh, PinStore, BiometricLock, DemoData, WidgetDataWriter
│       ├── ui/navigation/WimgNavigation.kt   routes + places menu
│       ├── ui/screens/        Home, Transactions, TransactionDetail, Recurring, RecurringDetail,
│       │                      Review, FinTS, Import, Search, Settings, About, Onboarding
│       └── widget/            Glance widgets: Monat, Fixkosten offen, Heute
│
├── wimg-sync-zig/             production sync + MCP server (native Zig)
└── wimg-sync/                 old Cloudflare Worker, rollback only
```
